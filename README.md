AGRINHO 2026

Sobre o projeto

Esse site mostra, de forma educativa, caso o campo(agro) parasse. Nele tem os dias 1, 7, 30 e 90, e mostra o que aconteceria ao longo dos dias.

Objetivo 

O site tem o objetivo de informar o leitor como as coisas aconteceriam, nele informa: cada dia economia vai quebrar vai quebrar mais, a população vai passar fome, etc.

Funcionalidades

Cadastro de nome e idade.
Etapas dos dias.
Imagens ilustrativas.
Curiosidades sobre o campo.
Modo escuro.

Justificativa 

Esse site foi desenvolvido para informar os usuários caso o campo parasse. O site busca mostrar informações de forma acessível, mostrando aos usuários o que aconteceria a cada dia.

Instruções 

Início: mostra o tema e pergunta idade e nome do usuário. 
Sobre: explica o que aconteceria se o campo parasse.
Impacto: mostra as consequências dos dias sem o agro falados no site.
